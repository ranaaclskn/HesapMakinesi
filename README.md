# Basit Hesap Makinesi

Python ile yazılmış, komut satırında çalışan basit bir hesap makinesi. Toplama, çıkarma, çarpma ve bölme yapar.

## Çalıştırma

```bash
python hesap_makinesi.py
```

Örnek:

```
İşlem seçin: +
Birinci sayı: 5
İkinci sayı: 3
Sonuç: 8
```

Çıkmak için `q` yazın.

## Testler

```bash
python -m unittest
```
